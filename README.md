# Neon Pong · 霓虹弹球对战

Free single-file HTML5 pong game against an AI. Neon glow, ball trails,
fireball combo mode, 3 difficulty levels, first to 7 points. One HTML
file, zero assets.

**Play:** https://shuangyueliao.github.io/neon-pong/

- Mouse / touch / arrow keys, procedural WebAudio sounds
- AI with reaction delay, speed limit and prediction error per difficulty
- Fireball: 5 straight paddle hits without a wall touch (faster ball, fire trail)
- Win/loss record saved locally, mute button
- Procedural neon visuals, no dependencies
